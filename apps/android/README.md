# Android workspace

This is the reserved home for a future native Android app. There is no Gradle
project, Android binary or Android test result yet.

Start with the [Android extension guide](../../docs/ANDROID.md). Reuse the Firebase
service and [shared contracts](../../shared/contracts/README.md). Implement Kotlin
domain rules against the shared fixtures, then add Compose, AlarmManager, CameraX
and platform-specific permission and lifecycle tests.
